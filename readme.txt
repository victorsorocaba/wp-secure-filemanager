== Description ==
Gerenciador de arquivos com controle de acesso baseado nas permissões nativas do WordPress e Multisite.

== Installation ==
1. Copie a pasta wp-secure-file-manager para wp-content/plugins/.
2. Ative o plugin no painel do WordPress.
3. Acesse o menu "Secure Files" para configurar permissões.
